免费 AI API 获取教程

只需 5 分钟，让 AI 问答用上你自己的免费 Key

本网站的 AI 问答需要你自己的 API Key（保存在你的浏览器本地，我们不保存、不转发）。推荐使用火山方舟的免费模型 Doubao-1.5-lite-32k，个人用户免费。
1
登入火山方舟：console.volcengine.com（需注册火山引擎账号）
2
点击左侧菜单 「在线推理」→ 「创建推理接入点」
3
输入接入点名称（随意，如 my-ai）→ 点击 「添加模型」
4
选择一款免费的大模型（推荐 Doubao-1.5-lite-32k）→ 确定
5
点击 「创建并接入」
6
在接入点详情页获取接入点 ID（形如 ep-2026xxxxxx-xxxxx）
7
在 「API Key 管理」中创建并获取 API Key（形如 xxxxxxxx-xxxx-xxxx）
8
回到本站，点击聊天面板右上角 ⚙️：先在「服务商」下拉选 火山方舟（会自动填好 API 地址），再填入 API Key 与 模型名 / 接入点 ID → 保存，完成！若网络或服务商不支持流式响应，可勾选 兼容模式（关闭流式 stream:false，SSE 受限时勾选），按普通 JSON 响应获取回复。

常见问题

安全吗？ Key 只存在你浏览器的 localStorage 里，本网站没有任何服务器，不存在泄露渠道。
收费吗？ 推荐的 Doubao-1.5-lite-32k 为免费模型；如你选用付费模型，费用由你的火山引擎账户承担。
换浏览器/换电脑要重新填吗？ 是。Key 存在当前浏览器里，换设备需重新粘贴一次。
测试连接或提问失败怎么办？ 若提示「API Key 无效或无权限（HTTP 401/403）」，请检查设置里的 API Key 与模型/接入点 ID 是否填对、Key 是否有效。若提示「请求未到达服务商」，可能原因包括：API Key 无效（部分服务商的 401/403 错误响应缺少 CORS 响应头，会被浏览器拦截成此类错误）、网络不通，或跨域(CORS)被拦截。请先核对 Key，再尝试更换网络，或换用支持浏览器直调的 OpenAI 兼容服务商（在「服务商」下拉中选择，或选「自定义」并相应更换 API 地址与模型名）。
可以用其他服务商吗？ 可以。只要兼容 OpenAI 的 /chat/completions 接口（DeepSeek、智谱、硅基流动等均可），填对应的 API 地址和模型名即可。
